PC-Center — Frontend Development
📌 Project Overview

PC-Center is a modern and responsive frontend website designed for an IT products and solutions business. The website provides users with an easy way to explore computer products, offers, categories, catalogues, and support services.

The design uses a dark professional theme with blue and purple gradients to create a modern technology-focused look.

🏠 Modern Home/Hero Section
🛒 Shopping Cart Interface
💻 IT Products Section
🏷️ Offers Section
📋 Product Catalogue
❓ Help & FAQ Section
📞 Contact Section
📱 Responsive Design
💬 WhatsApp Contact Button
📊 Business Statistics
🎨 Modern Dark UI

🔗 Responsive Navigation Bar
